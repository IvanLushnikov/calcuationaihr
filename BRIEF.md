# BRIEF — Лендинг ИИ Рекрутер «Калькулятор экономии найма»

## Контекст

Текущий файл `/Users/ivanlusnikov/calcuationaihr/index.html` — внутренний sales-калькулятор с кучей настраиваемых параметров (пакет минут, регион, конверсии, сценарии CPA). Это сложно, клиент теряется, а при настройке «20 вакансий» эффект часто отрицательный — клиент видит «минус по всем фронтам» и уходит хуже, чем после конкурентов.

**Руководитель попросил упростить вход:** клиент выбирает свою отрасль → мы автоматически подгружаем средние по отрасли (вакансии, отклики) → показываем расчёт стоимости пакета, минут, экономии vs конкуренты.

**Цель нового лендинга:** продающий one-page, на котором клиент за 30 секунд получает:
1. **Понимание своей ситуации** — «вот столько у вас вакансий и откликов в год».
2. **Экономическое обоснование** — «ИИ Рекрутер сэкономит X ₽ vs ручной найм, КЦ, ботов».
3. **Эмоциональный зацеп** — «вы теряете Y часов рекрутера в месяц, которые можно отдать делу».

## Сценарий пользователя

1. Заходит на страницу → видит сильный hero с заголовком и одним CTA «Узнать экономию».
2. Выбирает свою отрасль (карточки с иконкой + название).
3. Выбирает размер компании (5 сегментов).
4. Сразу видит результат:
   - **Hero-метрика**: «Экономия в год — X ₽» / «Y часов рекрутера освобождается».
   - **Что у вас происходит сейчас**: вакансий/год, откликов/год, интервью/год, часов ручного труда.
   - **Что даёт ИИ Рекрутер**: пакет минут, цена пакета, релевантных кандидатов, часов AI+контроль.
   - **Сравнение каналов** (CPA): ручной рекрутер / КЦ / сценарный бот / ИИ Рекрутер — столбиками или карточками, лучший выделен.
   - **Сценарии экономии**: vs штатный HR / vs КЦ по минутам / vs AI-SaaS.
5. CTA «Получить пилот» (форма обратной связи или ссылка на email).

## Технические требования

- **Single HTML file** с inline CSS + JS, подключением `<script src="data.js">` (или inline-данные).
- **Без сборки**, без npm. Открывается двойным кликом и работает на GitHub Pages.
- **Responsive**: десктоп + планшет + мобильный (лендинг, а не дашборд).
- **Тёмная палитра** (как в текущем): фон `#0f1419`, surface `#1a2332`, accent `#6366f1` (indigo), success `#34d399` (зелёный).
- **Шрифт**: системный sans-serif (-apple-system, Segoe UI, Roboto).
- **Анимации**: тонкие (fade-in, hover-lift), без кривляния.
- **Доступность**: aria-метки на интерактивных элементах, keyboard navigation.
- **Скорость**: <100KB JS, без сторонних библиотек.

## Что НЕ делать

- НЕ делать копию текущего калькулятора с кучей параметров.
- НЕ использовать placeholder Lorem Ipsum — все тексты на русском, продающие, без ИИ-слопа.
- НЕ писать «мы используем AI» без конкретики (что за AI, какие данные).
- НЕ вставлять отрасль «Другое» — лучше не выбрать, чем выбрать «Другое».
- НЕ ломать обратную совместимость — старый `index.html` оставить как есть, новый в отдельном файле (например, `index.html` перезаписывается — это основной продажный лендинг; backup старого → `calculator-internal.html`).

## Acceptance criteria

1. Лендинг выглядит **визуально круто и продажно** (не как внутренняя утилита).
2. Клиент за 30 секунд видит **свою ситуацию** (отрасль + размер).
3. Сразу видна **экономия в деньгах** (₽/год) и в **часах рекрутера**.
4. Видно **сравнение с 3 конкурентами** (ручной, КЦ, бот) с лучшим вариантом выделенным.
5. **CTA** в конце — понятный следующий шаг.
6. Работает офлайн, открывается двойным кликом, нет ошибок в консоли.
