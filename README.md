# Калькулятор эффекта ИИ Рекрутер

Sales-калькулятор для оценки экономики пилота ИИ Рекрутер.

## Использование

Откройте [калькулятор на GitHub Pages](https://ivanlushnikov.github.io/calcuationaihr/) или локально файл `index.html`.

## Модель

Калькулятор переводит пакет минут в ожидаемый объём телефонного этапа и оценивает время, которое команда могла бы потратить на те же действия вручную.

**Важно:** внутренняя модель, не гарантия клиенту. Телефония, маркировка, интеграция и НДС не включены.
